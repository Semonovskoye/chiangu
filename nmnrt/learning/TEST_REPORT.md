# NMNRT 2.3 — Learning-tab test and coverage report
29 September 2026

## What this release adds

732 explicitly authored learning statements over the frozen 2.2 reviewed question bank. Titles and takeaways were written as stand-alone teaching text, not generated by removing words or displaying wrong alternatives. Each uses its existing question ID; the original reviewed explanation, editorial note, source question and reference links remain accessible.

This release reorganizes the existing reviewed content for learning. It does not independently re-certify the biology or fill all missing curriculum material. Original raw lesson notes are never automatically promoted to learning statements.

## Content / scoring regression

- 17 automated test groups passed.
- All 732 questions map one-to-one to authored learning points and exactly one primary learning group.
- All point, question, section and reference IDs resolve.
- Missing source sections receive no invented learning text.
- All original 2.2 bank objects and the quiz core are unchanged.
- All 70,272 choice-scoring combinations passed (732 questions × 24 orders × 4 choices).
- Existing MCQ, short answer, recall and exam sessions still validate after serialization.
- Read/unread filters, invalid reading-backup rejection and timestamp-based merging were tested.

Automated scoring validates key handling, not the scientific correctness of each assertion.

## Browser checks

70 offline Chromium checks passed with no uncaught JavaScript errors. They cover:

- Separate learning/revision navigation and one shared theme selector.
- One-idea and whole-lesson views, section structure, source disclosures and search without accents.
- Correct Grade 9 scope and source-only chapter handling.
- Explicit read marks, continue/previous/skip, whole-lesson marking, and one-idea stopping.
- Reading marks do not alter quiz score records; quiz answers still create normal attempts.
- Exact-point and exact-section practice; lesson practice samples from that lesson only.
- Confirmation preserves an unfinished quiz when replacement is cancelled.
- Reading export/import and simulated state restoration.
- Light/Dark/System via the existing controller, black borders and readable control backgrounds.
- No horizontal overflow in library, reader or whole-lesson layouts at 320, 390 and 768 pixels.
- Existing procrastinator, short-answer, recall, exam and note modes.
- Blocked/corrupt reading storage and missing-learning-data fallback.
- Keyboard next/previous without silently marking content read.

### Environment limitation

A real navigation attempt to `http://127.0.0.1:8765/nmnrt/index.html#study` failed with `ERR_BLOCKED_BY_ADMINISTRATOR`. UI tests used `page.set_content` with the actual product HTML/JavaScript/CSS. Local images/fonts were embedded into the **test fixture only**. `localStorage` was mocked and reload was represented by restoring serialized state in a second fixture. OS theme changes were browser-emulated.

These tests do not establish live HTTP loading, deployed performance, native browser persistence, native cross-tab storage behavior, or Safari/Firefox support. No live-site deployment was performed. Font files and test-only embedded font data are not distributed.

## Preserved state and assets

The quiz storage namespace remains `nmnrt.v21.*`; the bank ID remains `nmnrt-reviewed-2026-09-29-v2.1`. The new reading state uses `nmnrt.reading.v1` and its own export format. Reset/import of read marks does not touch quiz records. The original `styles.css`, theme controller, homepage bridge, root HTML pages, mascot images and fonts remain in the existing site, not replaced by this patch.

The snapshot/count labels on the revision pages remain 2.2 because the question bank has not changed. Học nhanh is labelled 2.3.
